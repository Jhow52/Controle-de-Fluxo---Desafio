# 🧮 Contador com Validação de Parâmetros

Este projeto Java realiza uma contagem simples entre dois números inteiros fornecidos pelo usuário, com verificação de validade entre os parâmetros. É um ótimo exemplo de uso de exceções personalizadas e lógica básica de controle de fluxo.

---

## 🚀 Funcionalidades

✅ Solicita dois números inteiros ao usuário.  
✅ Verifica se o segundo número é maior que o primeiro.  
✅ Realiza a contagem entre os dois números.  
✅ Lança uma exceção personalizada em caso de erro.  

---

## 🧠 Lógica do Programa

1. O programa pede ao usuário dois valores inteiros.
2. Se o segundo for **menor** que o primeiro, uma exceção personalizada é lançada.
3. Se os valores forem válidos, o programa imprime os números entre eles (inclusive).

---

## 🛠️ Tecnologias

- Java 17+ (ou compatível)
- Terminal/Console
- IDEs recomendadas: IntelliJ IDEA, Eclipse ou VS Code com extensão Java

---

## ❌ Tratamento de Erros

O projeto utiliza a exceção personalizada `ParametrosInvalidosException` para lidar com entradas incorretas de forma elegante e compreensível para o usuário.
